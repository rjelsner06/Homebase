            Using

            Save up to 3 home screens. Each keeps its own laptop and phone layout. On a phone you can also press and hold the home screen to edit it.

            Links

              Links show in the row under the header and open in a pop-up. Drag ⋮⋮ (or use ↑ ↓) to reorder. Leave a web link's title blank to show just its symbol.

              Appearance

              The sun/moon button in the header switches the theme any time. On Automatic, that lasts until the next scheduled change.

              Notes color

              Types

              Drag ⋮⋮ to put them in your order. Types above the line show first when you pick a type for an item; the rest are under “Additional”. Checked types show in the to-do list (any single item can be switched in its details).

              Daily facts

              Refill asks the Ollama model on this laptop (server URL under AI-assisted import) for about 30 days of facts and saves them with your synced data, so your phone keeps showing them when the laptop is off. Run it on the laptop. Facts from a local model can be wrong. Add the Daily facts widget with Edit home screen → + Add widget.

              Reminders on your iPhone

              On your iPhone: install the free ntfy app, tap +, and subscribe to your topic on ntfy.sh. Each item can also have its own reminders (open the item). Supabase sends them at the right minute, even weeks ahead and with Homebase closed. Anyone who knows the topic can send you notifications, so keep it private.

              AI-assisted import

              When on, the import review screen gets an "Improve with AI" button. Nothing is added without your review.

              A local model only works on the computer it runs on, so this button won't work from your phone. Ollama blocks browser pages by default: set the environment variable OLLAMA_ORIGINS=* (or this page's address) and restart Ollama, e.g. OLLAMA_ORIGINS="*" ollama serve. On Windows, run setx OLLAMA_ORIGINS "*" in a terminal (or use your site's address, e.g. https://yourname.github.io), then quit Ollama from the system tray and reopen it. If the browser asks to allow access to devices on your local network, allow it. Safari may refuse http://localhost from an https page; Chrome and Firefox allow it.

              The key is saved only in this browser's storage, never in this file, and is sent only to api.anthropic.com. Anyone who uses this browser profile could read it.

                Import files into Notes

                PDF, Word (.docx) and PowerPoint (.pptx), up to 50 MB each. Pick several at once, or drop them here. The original files are kept in your Supabase file storage, so you can always download them.

                  PowerPoint: slides can't be shown reliably in a browser, so a .pptx on its own is kept for download only. To read it in the viewer, export it from PowerPoint as a PDF (File → Export → PDF) and import the PDF with the same name together with the .pptx: they're kept together as one note. You can also attach the PDF later from the viewer.

                  Files are kept in your Supabase project, so sign in to sync first.
